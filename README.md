# Chicago Development Pulse

An end-to-end analytics and business intelligence project analyzing
construction and development activity in Chicago.

## Project Goals

This project will build a complete analytics pipeline using public data
from the City of Chicago and other government sources.

The project will include:

- API data ingestion
- Python ETL/ELT pipelines
- PostgreSQL data storage
- dimensional data modeling
- automated data refreshes
- data visualization using Tableau and D3.js
- deployment using a Raspberry Pi

## Data Sources

Initial planned sources:

- City of Chicago Building Permits
- U.S. Census Bureau / American Community Survey

## Status
